Using the app

Think of a question and select any letter in the Shri Ram Shalaka grid. The app follows the traditional nine-letter sequence, matches the result with the corresponding chaupai, and displays its meaning and explanation.

You can choose Hindi or English, adjust the result text size, and use the reset button to begin another question. Siri and voice features are optional; the standard touch interface remains available if those system services are unavailable.
